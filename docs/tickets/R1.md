## Rules every ticket follows

- **Shared files belong to the lead** while tickets run: `src/shared/copy/en-IN.json`, `src/shared/testids.ts`,
  `src/shared/types.ts`, `src/shared/ipc.ts`, `src/shared/settings*.ts`, `src/shared/kit/catalog.ts`, `spec/trace.csv`,
  `design/tokens.json`, `src/renderer/cards/registry.ts`, the message block dispatcher in `src/renderer/messages/` (where a bubble picks markdown / a2ui / page / read line), and the engine system-prompt builder. T1 adds every registry entry, dispatcher case and prompt section as a stub; tickets fill their own component files only. A ticket that needs a key, id or type asks the lead and waits for the lead's push.
- Kit pieces use P1's motion tokens and `Presence`; no new motion rules, no animation library (02 §F7).
- No AI-generated code ever runs outside the AI page frame. The Calculator uses `shared/kit/evaluate.ts` only.
- Any Button or page action that would send, book, pay, delete or share opens an approval (Article 6). A form field that
  looks like a secret is refused and the Secret box is used (Article 8).
- Pictures are captured with motion off. Each ticket adds its own foo-verify journey `test/verify/r1-tNN-*.journey.ts`.
- Public repo: sample data only (example.com, fake numbers, fake places).
